# 敲敲淇淇 · 萌值小窝

一个敲击淇淇脑袋收集萌值的小网页，使用淇淇的自定义桌宠精灵图。

## 玩法

- 点击淇淇的脑袋或“敲一下”按钮增加萌值。
- 连敲奖励依次为 +1、+10、+1,000、+10,000……每一下的倍率再乘 10。
- 支持摸摸头、夸夸她、陪她玩、聊聊天，以及鼠标追视和长按摸头。
- 待机每 5 秒自动 +1 萌值，并说“哎呀不小心变萌了”；可在页面暂停。
- 全部动作使用原版淇淇精灵图，六种小动作随萌值解锁，可固定展示或自由活动。
- 萌值保存在当前浏览器；数字很大时会显示为中文数量级或科学计数法。

## 文件

- `index.html`：网页布局。
- `app.js`：互动、待机增长、解锁和计分逻辑。
- `interactions.css`：互动与动作小册样式。
- `assets/qiqi-spritesheet.webp`：淇淇桌宠动画精灵图。

目前使用精灵图动画，尚未接入 Live2D Cubism 模型。
