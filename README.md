# 敲敲淇淇 · 萌值小窝

一个敲击淇淇脑袋收集萌值的小网页，以及一只用同一张精灵图走动的桌面淇淇。角色始终是这张 `assets/qiqi-spritesheet.webp` 里的 2D 淇淇，不会换成别的动物或另一套画风。

## 网页

- 点击淇淇的脑袋或“敲一下”按钮增加萌值。
- 连敲奖励依次为 +1、+10、+1,000、+10,000……每一下的倍率再乘 10。
- 淇淇会轮流挥手、乖乖等待、偶尔跳跃和认真接住萌值。
- 萌值保存在当前浏览器；数字很大时会显示为中文数量级或科学计数法。
- 页脚的「桌面淇淇」会打开下面的网页预览（右键菜单、散步、拖拽拖尾都能试）。

本地直接打开 `index.html` 即可。推送到 `main` 后，GitHub Actions 会把仓库发布到 GitHub Pages，计分页面和桌面预览都会在上面。

## 桌面淇淇

桌面版是一个透明、始终置顶、不占用任务栏按钮的小窗口。右键打开菜单，左键点她会挥手，快速点两下会跳，按住拖拽时会落下粉色爱心和樱花。托盘图标可以叫她回来或退出。

Windows、macOS、Linux 都用同一套程序。窗口栖息在 Windows 上会读取当前打开的窗口；在 Linux 上如果装了 `xdotool` 也会读。读不到别的窗口时，她会坐到一块虚拟窗沿上，追逐和跳下仍然可用。

### 运行

需要 Node.js 18 或更新版本。

```bash
cd desktop
npm install
npm start
```

`npm start` 会打开淇淇。没有另做安装包；在 Windows 上同样是这两步。Linux 上透明窗口走了软件渲染，如果发行版拦住了沙箱，程序已经自行关掉沙箱，一般不用再加参数。

### 菜单

- **动作**：挥手、跳跃、等待、认真看、睡觉。这些都是精灵图上的既有帧。
- **走动**
  - 任务栏散步：默认开。她沿着工作区底边走，走到头会挥手，偶尔停下来等待或眯一下。
  - 桌面闲逛：默认关。打开后她会在桌面里走向随机位置。若和任务栏同时开着，两种走动大约每 22 秒轮换。
  - 自动栖窗追逐：默认开。过一会儿她走到某个窗口顶上坐下；鼠标靠近就追着光点跑，然后跳回下面。菜单里的「现在去栖窗」「追逐鼠标」「跳回下面」可以立刻做这些事。
- **花样**
  - 矩阵滤镜：默认关。打开后仍是淇淇的轮廓，只是用字符重画，粉色部分保持粉色。
  - 拖拽爱心樱花：默认开。只有按住拖她的时候才出现。
  - 小捣蛋模式：默认关。打开后她偶尔自己挪一小段、说一句，不会改你的文件，也不会去关别的程序。

行为都写在 `desktop/renderer/plugins.js` 里，每个插件有自己的开关和默认值。设置记在本机 `localStorage`（`qiqi-desktop-settings-v1`）。

精灵图上没有单独的降落伞。从窗口上离开时，如果 `assets/actions/` 里还没有一整套 `qiqi_parachute_01.png` 起的连帧，她就用跳跃那一行的腾空帧往下掉。

## 精灵图

`assets/qiqi-spritesheet.webp` 是 1536×2288 的透明图，**8 列 × 11 行**，每格 **192×208**。网页计分用到的挥手、等待、跳跃、查看，和桌面版是同一格。

| 行 | id | 帧 | 做什么 |
| --- | --- | --- | --- |
| 0 | `idle` | 0–6 | 待机、眨眼 |
| 1 | `walkRight` | 0–7 | 向右走；追逐时加快 |
| 2 | `walkLeft` | 0–7 | 向左走；追逐时加快 |
| 3 | `wave` | 0–3 | 挥手（网页同一行） |
| 4 | `jump` | 0–4 | 跳跃。下落只用第 3 格（`fall`） |
| 5 | `sit` | 0–7 | 栖在窗口上时的安静循环 |
| 6 | `wait` | 0–5 | 等待（网页同一行） |
| 7 | `notice` | 0–5 | 短反应，追逐开始和小捣蛋收尾会用 |
| 8 | `review` | 0–5 | 认真看（网页同一行） |
| 9 | `settle` | 0–7 | 坐下前低下头，播完一次接到 `sit` |
| 10 | `sleep` | 0–7 | 睡觉 |

这些行里，1 和 2 是同一套跨步、左右各画了一遍，所以散步和追逐都用它们，只是追逐把帧速加快。第 5 行几乎站着不动、身子也更收，用来当栖窗。没有单独的奔跑图。

现在还空着的格子：第 0 行第 8 格，第 3 行后四格，第 4 行后三格，第 6、7、8 行的最后两格。列号从 0 数。

### 加新动作

新的动作必须还是这张精灵图里的淇淇：同一张脸、圆框眼镜、兔耳、粉白女仆裙，线的粗细和上色也要一致。每个动作是一套过渡连帧，不是一张静帧。少于 4 张的片段不会被采用，桌宠会继续播原来的精灵图。

有两条路，优先把帧画进大图；连帧很多、画幅更高（比如降落伞）时再用编号文件。

1. **往现有精灵图加帧**：空格子见上表。把列号写进 `desktop/renderer/catalog.js` 里那个动作的 `frames`。`frameMs` 可以是每一帧的毫秒数组，或一个共用数字。
2. **大图多一行**：先改图片，再把 `SHEET.rows` 改成新的行数。帧宽高必须仍能整除。网页计分按 8 列 × 11 行切，`background-size` 是 `800% 1100%`，加一行时这两处要一起改。编号文件不碰网页。
3. **编号连帧**（桌宠会自己找，不用改代码）：放进 `assets/actions/`，从 `01` 连续编号，中间不要断号，每个文件同一像素尺寸，脚靠近下边缘，背景透明。加载器最多读到 24 张。

| 动作 | 文件 | 没有这些文件时 |
| --- | --- | --- |
| 栖窗 | `qiqi_perch_01.png` … | 精灵图第 9 行低头，再接到第 5 行 |
| 追逐 | `qiqi_chase_01.png` … | 第 1、2 行走路，帧速加快 |
| 追逐左右分绘 | `qiqi_chase_left_01.png`、`qiqi_chase_right_01.png` | 只有一套时，向左会水平翻转 |
| 降落伞 | `qiqi_parachute_01.png` … | 跳跃行的腾空帧 |
| 小捣蛋 | `qiqi_gremlin_01.png` … | 第 7 行短反应 |
| 睡觉 | `qiqi_sleep_01.png` … | 第 10 行 |
| 看书 | `qiqi_read_01.png` … | 第 8 行认真看 |
| 任务栏走 | `qiqi_taskbar_01.png` … | 第 1、2 行 |
| 任务栏左右分绘 | `qiqi_taskbar_left_01.png`、`qiqi_taskbar_right_01.png` | 只有一套时，向左会水平翻转 |

桌面闲逛和拖着走始终用第 1、2 行。只有任务栏散步会去找 `qiqi_taskbar`。一张静帧、或只有两三张的片段，都不会换掉精灵图。

举例：追逐八帧就是 `qiqi_chase_01.png`、`qiqi_chase_02.png`，一直到 `qiqi_chase_08.png`。八帧是预期的一套；四帧起才会替换精灵图，多于八帧也可以，只要编号连续。

左右两套是分开画的最好，因为原来的走路就是左右各画了一行，不是镜像。网页计分仍然只用大图。

`desktop` 里的 `npm test` 会检查精灵图动作没有指到空格子，也会检查上述文件名和「不足四帧就回退」。

## 文件

- `index.html`：网页布局、敲击和计分。
- `assets/qiqi-spritesheet.webp`：淇淇的桌宠精灵图。
- `desktop/`：Electron 桌面壳、菜单和可开关的行为插件。
- `.github/workflows/pages.yml`：把仓库发布到 GitHub Pages。
